# SportShop — Практическое занятие 7

Учебный проект по ветвлению и слиянию в Git. В репозитории сохранена локальная Git-история: `main`, `develop`, feature-ветки, разрешённый merge-конфликт и hotfix. См. отчёты в `docs/08`–`docs/12`.

Для просмотра истории выполните `git log --oneline --graph --all`. Ветка `feature/search-advanced` оставлена как имитация PR, ожидающего ревью; остальные завершённые рабочие ветки удалены после слияния.
