# Разрешение конфликта слияния

В `feature/total-v1` функция `total_sum` суммировала цену каждой товарной записи. В `feature/total-v2` она умножала цену на количество. Обе ветки изменили одну строку в `shop.py`, поэтому при слиянии второй ветки Git остановился с конфликтом.

Разрешение: оставлена версия с учётом количества — `sum(price * quantity)`. Если количество не задано, оно считается равным 1. Маркеры конфликта удалены, файл добавлен в индекс, слияние завершено коммитом `Разрешён конфликт в total_sum`.

Проверить итоговую функцию можно на примере товаров `{price: 100, quantity: 2}` и `{price: 50, quantity: 1}`: результат должен быть 250.
